第一章 集合与常用逻辑用语

常用数集符号
自然数集 N（含0）；正整数集 N* 或 N₊；整数集 Z；有理数集 Q；实数集 R；复数集 C
集合的表示法
列举法（{ }列出元素）、描述法（{x | x 满足的性质}）
集合三要素
确定性、互异性、无序性
子集与真子集
若 A 中任意元素都在 B 中，则 A ⊆ B。若 A ⊆ B 且 A ≠ B，则 A ⊊ B；空集 ∅ 是任何集合的子集，是任何非空集合的真子集
子集个数（重要）
含 n 个元素的集合，子集 2ⁿ 个，真子集 (2ⁿ−1) 个，非空子集 (2ⁿ−1) 个，非空真子集 (2ⁿ−2) 个
交集、并集、补集
A∩B = {x | x∈A 且 x∈B}；A∪B = {x | x∈A 或 x∈B}；∁ᵤA = {x | x∈U 且 x∉A}
德摩根定律
∁ᵤ(A∩B) = (∁ᵤA)∪(∁ᵤB)；∁ᵤ(A∪B) = (∁ᵤA)∩(∁ᵤB)
充分条件与必要条件
若 p⇒q，则 p 是 q 的充分条件，q 是 p 的必要条件。p⇔q 则互为充要条件。口诀：小范围⇒大范围（小是大充分，大是小必要）
全称量词与存在量词及其否定
全称命题 ∀x∈M, p(x) 的否定是 ∃x∈M, ¬p(x)；存在命题 ∃x∈M, p(x) 的否定是 ∀x∈M, ¬p(x)。口诀：改量词、否结论

第二章 一元二次函数、方程和不等式

等式性质与不等式性质
a>b ⇔ a−b>0；对称性 a>b⇔b<a；传递性 a>b,b>c⇒a>c；可加性 a>b⇒a+c>b+c；可乘性 a>b,c>0⇒ac>bc（c<0 时方向改变）
基本不等式（均值不等式）
若 a,b>0，则 (a+b)/2 ≥ √(ab)，当且仅当 a=b 时取等号。口诀：一正、二定、三相等。变式：a²+b²≥2ab；ab ≤ [(a+b)/2]²
求最值两类
积定和最小：xy 为定值 p 时，x+y 最小为 2√p；和定积最大：x+y 为定值 S 时，xy 最大为 S²/4
一元二次方程求根公式
ax²+bx+c=0 (a≠0) 的解 x = [−b ± √(b²−4ac)] / (2a)
判别式
Δ = b²−4ac；Δ>0 两个不等实根；Δ=0 两个相等实根（重根）；Δ<0 无实根
韦达定理（根与系数关系）
若 x₁,x₂ 是 ax²+bx+c=0 的两根，则 x₁+x₂ = −b/a，x₁x₂ = c/a
解一元二次不等式
ax²+bx+c>0 (a>0)：两根之外（大于取两边）；ax²+bx+c<0 (a>0)：两根之间（小于取中间）。a<0 时先变号
分式不等式
f(x)/g(x)>0 ⇔ f(x)·g(x)>0；f(x)/g(x)≥0 ⇔ f(x)·g(x)≥0 且 g(x)≠0

第三章 函数的概念与性质

函数概念
设 A、B 是非空数集，若对 A 中每个元素 x，按确定的对应关系 f，B 中都有唯一 y 与之对应，则称 f:A→B 为函数。x 自变量，定义域 A，值域 {f(x)|x∈A}
函数三要素
定义域、值域、对应关系（两个函数相等 ⇔ 三要素都相同）
函数定义域（常见限制）
分母≠0；偶次根号内≥0；对数真数>0；f(x)⁰ 的底数≠0；正切函数 x≠π/2+kπ
单调性定义
对区间 D 内任意 x₁<x₂：若 f(x₁)<f(x₂) 则增函数；若 f(x₁)>f(x₂) 则减函数。用于比较大小和解不等式
单调性运算性质
增+增=增，减+减=减，增−减=增，减−增=减。复合函数单调性：同增异减
奇偶性定义
f(−x)=f(x) 为偶函数（图象关于 y 轴对称）；f(−x)=−f(x) 为奇函数（图象关于原点对称）。前提：定义域关于原点对称
奇偶性性质
奇±奇=奇，偶±偶=偶，奇×奇=偶，偶×偶=偶，奇×偶=奇；奇函数若在 x=0 处有定义则 f(0)=0
幂函数
形如 y = x^α 的函数。α>0 时过 (0,0)、(1,1)，在第一象限递增；α<0 时过 (1,1)，以坐标轴为渐近线递减。常见：y=x、y=x²、y=x³、y=x^(1/2)、y=x^(−1)
一次函数与二次函数
一次 y=kx+b (k≠0)。二次 y=ax²+bx+c (a≠0)，顶点 (−b/2a, (4ac−b²)/4a)，对称轴 x=−b/2a；a>0 开口向上有最小值，a<0 开口向下有最大值
分段函数
不同区间有不同解析式，求值时先判断自变量落在哪个区间

第四章 指数函数与对数函数

指数幂运算法则
aᵐ·aⁿ = aᵐ⁺ⁿ；aᵐ÷aⁿ = aᵐ⁻ⁿ；(aᵐ)ⁿ = aᵐⁿ；(ab)ⁿ = aⁿbⁿ；(a/b)ⁿ = aⁿ/bⁿ（a>0）
根式与分数指数幂
ⁿ√(aᵐ) = a^(m/n)；a⁰=1 (a≠0)；a^(−n)=1/aⁿ
指数函数
y=aˣ (a>0 且 a≠1)：a>1 增函数，0<a<1 减函数；恒过 (0,1)；定义域 R，值域 (0,+∞)
对数定义（指数对数互化）
aᵇ=N ⇔ b=logₐN（a>0 且 a≠1，N>0）
对数恒等式
a^(logₐN) = N；logₐ1 = 0；logₐa = 1
对数运算法则
logₐ(MN) = logₐM + logₐN；logₐ(M/N) = logₐM − logₐN；logₐ(Mⁿ) = n·logₐM
换底公式
logₐb = log꜀b / log꜀a；推论 logₐb = 1/logᵦa
对数函数
y=logₐx (a>0 且 a≠1)：a>1 增函数，0<a<1 减函数；恒过 (1,0)；定义域 (0,+∞)，值域 R
指数函数与对数函数互为反函数
y=aˣ 与 y=logₐx 互为反函数，图象关于直线 y=x 对称
指数/对数不等式
a>1 时 aˣ 单调递增：aˣ<aʸ ⇔ x<y；0<a<1 时单调递减。对数不等式同理（真数必须>0）

第五章 三角函数

角度与弧度换算
180° = π 弧度；1° = π/180；1 弧度 = (180/π)° ≈ 57.3°
弧长与扇形面积
弧长 l = |α|·r；扇形面积 S = (1/2)l·r = (1/2)|α|r²
任意角三角函数定义
角 α 终边与单位圆交点 P(x,y)，则 sinα=y，cosα=x，tanα=y/x。终边上任一点 P(x,y) 距原点 r：sinα=y/r，cosα=x/r，tanα=y/x
各象限三角函数符号
口诀：一全正、二正弦、三正切、四余弦（只有该象限对应函数为正）
同角三角函数基本关系
平方关系 sin²α+cos²α=1；商数关系 tanα = sinα/cosα
诱导公式
口诀：奇变偶不变，符号看象限。sin(−α)=−sinα、cos(−α)=cosα；sin(π−α)=sinα、cos(π−α)=−cosα；sin(π+α)=−sinα 等
特殊角三角函数值
sin：0°=0, 30°=1/2, 45°=√2/2, 60°=√3/2, 90°=1；cos 与之对应递减；tan：0, √3/3, 1, √3, 不存在
正弦函数 y=sinx
定义域 R，值域 [−1,1]，周期 2π，奇函数；单调增区间 [−π/2+2kπ, π/2+2kπ]；x=π/2+2kπ 取最大 1，x=−π/2+2kπ 取最小 −1
余弦函数 y=cosx
定义域 R，值域 [−1,1]，周期 2π，偶函数；单调增区间 [−π+2kπ, 2kπ]；x=2kπ 取最大 1，x=π+2kπ 取最小 −1
正切函数 y=tanx
定义域 x≠π/2+kπ，值域 R，周期 π，奇函数；在每个区间 (−π/2+kπ, π/2+kπ) 上递增
y=Asin(ωx+φ) 图象与性质
振幅 |A|；周期 T=2π/|ω|；相位 ωx+φ，初相 φ。A 影响纵向伸缩，ω 影响横向伸缩（周期），φ 影响左右平移（左加右减）
三角恒等变换公式
两角和差、二倍角、辅助角等公式（详见后续三角恒等变换专题，本章为三角函数基础图像与性质）
